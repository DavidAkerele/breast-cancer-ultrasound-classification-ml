# Superseded artifacts

Files below this directory are retained only for provenance. They are **not submission evidence** and must not be cited as measured results.

- `legacy_illustrative_figures/` contains charts and diagrams from an earlier interface that embedded static or simulated values.
- `legacy_exports/` contains earlier Word and PowerPoint exports with outdated modality names and unsupported claims.

The current dissertation uses figures generated by `evaluate.py`, while the current Word and PowerPoint files are rebuilt from the evidence-aware source.
